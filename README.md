# SEVEN TO SMOKE 2027

Premium responsive PWA prototype for the African Urban Dance Championship 2027.

## Stack
- React 18 + TypeScript
- Vite 6
- Lucide React
- PWA manifest and service worker

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

Vite outputs the production site to `dist/`.

## Deploy on Vercel
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Before public launch
- Confirm the official event date, venue, selection and prize details.
- Replace temporary photography with authorized event assets.
- Validate the contact email and connect a real contact workflow.
- Add official logos only with permission.
- Add privacy notice and consent handling before analytics or marketing collection.
- Connect a secure backend only if required; never expose Supabase service-role keys in the browser.
